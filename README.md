## 1. GIỚI THIỆU

Repository này lưu trữ các bài thực hành JavaScript
thuộc học phần Phát triển ứng dụng Thương mại điện tử.

Nội dung gồm 03 bài Lab:

- Lab 08: JavaScript 1 – Language Foundations
- Lab 09: JavaScript 2 – DOM and Events
- Lab 10: JavaScript 3 – jQuery

Ngoài các bài thực hành, thư mục còn có trang
index.html dùng để giới thiệu thông tin sinh viên,
tổng hợp kiến thức và liên kết đến từng bài Lab.

## 2. MỤC TIÊU THỰC HIỆN

- Nắm vững các kiến thức cơ bản về JavaScript.
- Biết sử dụng biến, hàm, mảng và đối tượng.
- Thực hành thao tác với DOM và xử lý sự kiện.
- Biết kiểm tra dữ liệu đầu vào của biểu mẫu.
- Sử dụng jQuery để lựa chọn và thao tác phần tử HTML.
- Tạo các hiệu ứng tương tác và chuyển động.
- Thực hành gửi yêu cầu GET và xử lý dữ liệu JSON.
- Rèn luyện kỹ năng sử dụng Visual Studio Code.
- Sử dụng Git và GitHub để quản lý mã nguồn.
- Triển khai website bằng GitHub Pages.

## 4. NỘI DUNG CÁC BÀI LAB

### 4.1. Lab 08 – JavaScript 1: Language Foundations

Lab 08 tập trung vào những kiến thức nền tảng
của ngôn ngữ JavaScript.

Nội dung thực hành:

- Tích hợp JavaScript vào trang HTML.
- Khai báo và sử dụng biến.
- Thực hiện các phép toán và biểu thức.
- Sử dụng câu lệnh điều kiện và vòng lặp.
- Xây dựng và gọi hàm.
- Làm việc với Array và Object.
- Sử dụng Browser Console để kiểm tra kết quả.

**Kết quả:** Hiểu cách JavaScript xử lý dữ liệu
và thực hiện các thao tác lập trình cơ bản.

### 4.2. Lab 09 – JavaScript 2: DOM and Events

Lab 09 tập trung vào việc tương tác với các
phần tử HTML thông qua DOM và Events.

Nội dung thực hành:

- Truy xuất các phần tử trong DOM.
- Thay đổi nội dung và thuộc tính HTML.
- Thao tác với cấu trúc trang web.
- Đăng ký và xử lý các sự kiện.
- Xử lý tương tác của người dùng.
- Làm việc với biểu mẫu HTML.
- Kiểm tra dữ liệu đầu vào (Form Validation).

**Kết quả:** Biết sử dụng JavaScript để cập nhật
giao diện và xử lý các thao tác của người dùng.

### 4.3. Lab 10 – JavaScript 3: jQuery

Lab 10 tập trung vào thư viện jQuery và
các chức năng tương tác nâng cao.

Nội dung thực hành:

1. Exercise 10.1 – Set Up jQuery
2. Exercise 10.2 – Basic Selectors
3. Exercise 10.3 – Advanced Selectors
4. Exercise 10.4 – jQuery Listeners
5. Exercise 10.5 – Inserting DOM Elements
6. Exercise 10.6 – Simple jQuery Animation
7. Exercise 10.7 – More jQuery Animation
8. Exercise 10.8 – Complex Animations
9. Exercise 10.9 – GET Requests
10. Exercise 10.10 – jqXHR Handling

**Kết quả:** Biết sử dụng jQuery để thao tác DOM,
xử lý sự kiện, tạo hiệu ứng Animation và
gửi yêu cầu GET đến dịch vụ web.

## 6. HƯỚNG DẪN TRUY CẬP BÀI THỰC HÀNH

### Cách 1: Truy cập trực tuyến

**Bước 1:** Mở đường dẫn GitHub Pages ở mục 5.2.

**Bước 2:** Tại trang chủ, chọn Lab 08,
Lab 09 hoặc Lab 10.

**Bước 3:** Chọn bài thực hành muốn kiểm tra.

**Bước 4:** Thực hiện các thao tác trên giao diện
để quan sát kết quả JavaScript.

### Cách 2: Chạy trên Visual Studio Code

**Bước 1:** Tải repository từ GitHub về máy.

**Bước 2:** Mở thư mục dự án bằng VS Code.

**Bước 3:** Cài đặt tiện ích Live Server.

**Bước 4:** Mở file index.html hoặc file HTML
của bài thực hành cần kiểm tra.

**Bước 5:** Nhấp chuột phải và chọn
Open with Live Server.

**Bước 6:** Quan sát kết quả trên trình duyệt.
Có thể nhấn F12 để mở Developer Tools và
kiểm tra Console hoặc Network khi cần.
